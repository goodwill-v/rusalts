Система ведения реестра акционеров

Автоматизированная система для ведения и обновления реестра акционеров с интеграцией данных ЕГРЮЛ и ЕГАР. Формирование отчётности в ФНС, учёт перехода прав, дробления долей, сплитования, обременений. Подготовка документов для корпоративных действий (собрания, голосования, дивиденды). Экспорт в формат, принимаемый регистраторами и депозитариями.

Корпоративный учёт Python / FastAPI React-дашборд ЕГРЮЛ / ЕГАР

Платформа поставщиков для Хорика

Экосистема закупок и управления поставщиками: каталог товаров и услуг, автоматическая загрузка и сравнение коммерческих предложений, торги и тендеры, рейтинг поставщиков. Модуль планирования закупок с AI-прогнозом потребностей на основе истории. Интеграция с 1С: поступление заявок — автоматическое формирование заказов.

Торговля / Снабжение Python / FastAPI React / Next.js 1С интеграция

AI-автоматизация цикла заявка → КП

LLM-парсинг неструктурированных прайсов (Excel, PDF) с произвольной схемой — двухпроходный AI-парсер: сначала определяет структуру, затем извлекает данные. Интеграция с amoCRM: заявка → поиск товаров → генерация КП в PDF — без участия менеджера. Веб-кабинет для ручной корректировки. Стек: Python, FastAPI, GigaChat, PostgreSQL, React.

LLM / GigaChat Python / FastAPI amoCRM API PDF-генерация

Тендерный ИИ-отдел (4 AI-агента)

Мультиагентная система для автоматизации тендерного отдела на платформе Make + LLM. Агент 1: поиск тендеров по API Контур.Закупки с дедупликацией. Агент 2: анализ документации и извлечение ключевых условий. Агент 3: просчёт стоимости (s4b.ru API) и маржинальности. Агент 4: заполнение шаблона заявки и отправка на утверждение. Оркестратор + Telegram-бот для контроля.

Multi-agent Telegram-бот API-интеграции Тендеры

Сквозная аналитика «клик → сделка»

Полный цикл сквозной аналитики: Яндекс Метрика + Google Tag Manager + Facebook Pixel + Wazzup + YourGoodWidget. Настройка воронки от клика до оплаченной сделки, атрибуция по UTM-меткам, дашборд в Яндекс DataLens. Тестирование по каждому каналу, инструкция для самостоятельного контроля.

Сквозная аналитика Wazzup / YGW Яндекс Метрика GTM / DataLens
