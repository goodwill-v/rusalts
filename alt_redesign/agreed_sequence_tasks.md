## 2. Детали по каждому пункту

### Шаг 1. Редизайн сайта (Задача 3)
- **Исполнитель:** ZCode
- **Содержание:** ревизия дизайна, улучшение образа, эффектность графики, соответствие трендам, рефакторинг для эффективности
- **Технология:** GLM-5.3 + Browser Preview (реальные страницы) + Vision (референсы)
- **Стек остаётся:** FastAPI + HTML-шаблоны + CSS/JS (без смены фреймворка)

### Шаг 2. Админка универсальная (Задача 1)
- **Исполнитель:** ZCode
- **Решение:** Универсальная админ-панель для всего сайта (не только витрина)
- **Аргументация Шефа одобрена:**
  - Уже есть зачаток биллинг-админки — расширяем
  - Парсер, контент, диагностика, заказы — всё ляжет в одну панель
  - Единая точка входа для администрирования
- **MVP-функционал:** управление товарами, заказами, диагностиками, контентом

### Шаг 3. Витрина продуктов (Задача 5)
- **Исполнитель:** Шеф + Алик (ручное тестирование перед агентом)
- **Действие:** привести в рабочее состояние все продукты, протестировать переходы на реальный продукт и систему оплаты
- **Утверждение:** до запуска внешнего агента

### Шаг 4. Бесплатная диагностика (Задача 2)
- **Исполнитель:** Обсуждение Шеф + Алик + привлечение ZCode
- **Основа алгоритма:** предложение Алика (анкета → LLM-анализ → PDF-отчёт → Upsell)
- **Требуется уточнение:** вопросы анкеты, портрет аудитории, механика воронки

### Шаг 5. Парсер + автоконтент (Задача 4)
- **Статус:** ⏳ Ожидает анализа от Шефа
- **Известные проблемы:** неработающий конвейер парсинга и публикаций
- **Детали:** уточняются

## 3. Технические решения

### Мультиагентность в ZCode
- ✅ ZCode поддерживает custom subagents (`/agent`) — каждый со своей моделью и инструментами
- Один goal может подключать несколько суб-агентов (frontend, backend, content)
- Для полного параллелизма — запускать отдельные сессии ZCode

### Деплой
| Этап | Стратегия |
|------|-----------|
| **Триал (5 дней)** | Локально на сервере, коммит одной порцией в конце |
| **Активная работа** | ZCode сам делает git commit → push → GitHub Actions → деплой |
| **Финал** | Вернуться к штатному процессу |

### Просмотр страниц ZCode
- **Live Browser Preview** — встроенный браузер, показывает реальные страницы сайта (не скриншоты)
- Агент кликает, читает DOM, видит изменения CSS/JS в реальном времени
- **GLM-5.3-Flash Vision** — опционально, для анализа скриншотов и референсов
