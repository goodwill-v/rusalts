> **Инструменты:** ZCode (GLM-5.3), Hindsight (persistent memory), BigModel API trial

## 1. Регистрация и установка

### 1.1 Аккаунт Z.ai (международный)
- [ ] Зарегистрироваться на [z.ai](https://z.ai) — **по email**, китайский телефон не нужен
- [ ] Подтвердить email
- [ ] Войти в ZCode через аккаунт Z.ai (кнопка *Continue with Z.ai*)

### 1.2 Установка ZCode
- [ ] Скачать ZCode с [zcode.z.ai/en](https://zcode.z.ai/en) под свою ОС (Linux, macOS, Windows)
- [ ] Установить, запустить
- [ ] Подключить аккаунт Z.ai → активируется **5-дневный триал**:
  - GLM-5.3: **3M токенов/день**
  - GLM-5-turbo: **2M токенов/день**
  - **Итого: 5M токенов/день × 5 дней = 25M токенов**

### 1.3 (Опционально) BigModel API
- [ ] Если есть доступ к китайскому номеру (+86) — зарегиться на [open.bigmodel.cn](https://open.bigmodel.cn)
- [ ] Получить ещё **8M токенов/день × 5 дней** (не пересекается с ZCode trial)
- [ ] Подключить API-ключ в ZCode на вкладке BigModel

## 2. Установка Hindsight (персистентная память)

### 2.1 Выбор способа

| Режим | Ресурсы | Цена |
|-------|---------|------|
| **Self-hosted (Docker)** | ~200-300 МБ ОЗУ, 1 ядро | Бесплатно (MIT) |
| **Hindsight Cloud** | ничего не нужно | Pay-as-you-go от $10/mln токенов |

**Рекомендация:** self-hosted на сервере (можно на той же машине, где стоит ZCode).

### 2.2 Self-hosted (Docker)
```bash
# 1 команда
docker run --rm -it -p 8888:8888 -p 9999:9999 \
  -e HINDSIGHT_API_LLM_API_KEY=$OPENAI_API_KEY \
  -v $HOME/.hindsight-docker:/home/hindsight/.pg0 \
  ghcr.io/vectorize-io/hindsight:latest
```

### 2.3 Установка хуков в ZCode

**Через плагин ZCode (рекомендуется):**
```bash
zcode plugins add-marketplace vectorize-io/hindsight
zcode plugins install hindsight-zcode
```

**Или через pip:**
```bash
pip install hindsight-zcode
hindsight-zcode install --api-url http://localhost:8888 --api-token hsk_your_token
```

### 2.4 Конфигурация
- [ ] Создать `~/.hindsight/zcode.json`:
  ```json
  {
    "hindsightApiUrl": "http://localhost:8888",
    "hindsightApiToken": "hsk_your_token",
    "dynamicBankId": true
  }
  ```
- [ ] `dynamicBankId: true` — изолирует память по проектам (папкам)
- [ ] Перезапустить ZCode

## 3. Инициализация памяти проекта АЛТ

### 3.1 Первичное наполнение памяти
Запустить в ZCode первый `goal` с инструкцией запомнить контекст:

> **/goal** Запомни структуру и архитектуру сайта АЛТ для редизайна.
>
> 1. Прочитай все файлы в /opt/alt/ — изучи текущую структуру
> 2. Сохрани в память: архитектуру, стек технологий, цветовую схему, шрифты, особенности вёрстки
> 3. Сохрани договорённости: что меняем, что оставляем, какие ограничения
> 4. Сохрани ссылки на референсы и макеты (когда появятся)

### 3.2 Проверка памяти
- [ ] Закрыть ZCode
- [ ] Открыть заново
- [ ] Задать вопрос: *«Какая архитектура у сайта АЛТ?»*
- [ ] Агент должен ответить из памяти, не читая файлы заново

## 4. Расписание работы (часы пик — множитель 3×)

### 4.1 Актуальные множители (октябрь 2026)

| Часы (ЕКБ) | Множитель | Рекомендация |
|-------------|-----------|--------------|
| 11:00–15:00 | **3× (Peak)** | Избегать, только если срочно |
| 15:00–11:00 | **2× (Off-peak)** | Основное время работы |
| Выходные | **Вне пика** | Лучшее время для сложных задач |

### 4.2 Стратегия экономии кредитов
- **Сложное (редизайн, архитектура)** — до 11:00 или после 15:00 ЕКБ
- **Рутинное (стили, фиксы)** — на GLM-5.3-Flash (дешевле)
- **При достижении лимита 5-часового окна** — перерыв или ручная работа

## 8. ⚠️ Важные ограничения

| Что | Детали |
|-----|--------|
| **Триал только 5 дней** | После окончания — или подписка, или блок |
| **BigModel требует +86** | Без китайского номера — недоступен |
| **ZCode не editor-first** | Не Cursor с tab-complete — агентный подход |
| **Hindsight self-hosted** | Нужен Docker на машине или рядом на сервере |
| **Китайские сервера** | Cloud-режим Z.ai идёт через сервера в КНР. Self-host GLM + Hindsight = полный контроль |
