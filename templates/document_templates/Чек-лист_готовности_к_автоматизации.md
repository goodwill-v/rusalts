# Чек-лист: Готовность вашего бизнеса к автоматизации

> Пройдите за 5 минут. Отметьте что уже есть/работает — получите ориентир, с чего начать.

## 1. Процессы (что можно автоматизировать)

- [ ] Типовые вопросы клиентов повторяются каждый день (10+ раз)
- [ ] Рассылки/уведомления отправляются вручную
- [ ] Сбор заявок/данных — через форму на почту
- [ ] Мониторинг сайта/сервисов — «заметил когда упало»
- [ ] Черновики контента пишутся с нуля каждый раз
- [ ] Звонки/встречи конспектируются вручную

**Чем больше галочек — тем больше потенциал автоматизации.**

## 2. Данные

- [ ] Знаю, где хранятся данные клиентов
- [ ] Есть политика обработки ПДн (или знаю, что нужна)
- [ ] Понимаю, какие данные можно передавать ИИ, а какие нет

## 3. Ресурсы

- [ ] Готов(а) выделить 2 недели на пилот
- [ ] Бюджет на инструменты: от 150 ₽/мес
- [ ] Есть человек, который будет тестировать (даже если это вы)

## 4. Результат

**0–3 галочки** → Начните с бесплатной диагностики (5 мин): rusalts.ru/diagnostics/free/
**4–7** → Выберите 1 процесс и запустите пилот (ВежПом или ИИ-ассистент)
**8+** → Готовы к автономизации! Анализ процессов (3000 ₽) — с дорожной картой.
