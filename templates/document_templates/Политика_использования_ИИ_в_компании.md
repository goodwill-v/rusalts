# Политика использования ИИ в компании (шаблон)

> Утвердите для сотрудников. Заполняет руководитель.

## 1. Общие принципы

- ИИ — инструмент повышения эффективности, не замена человека
- Ответственность за результат всегда на человеке
- Конфиденциальность — приоритет

## 2. Что МОЖНО делать с ИИ

- [ ] Генерировать черновики текстов (презентации, письма, отчёты)
- [ ] Суммаризировать длинные документы
- [ ] Искать идеи и варианты решений
- [ ] Переводить тексты
- [ ] Писать код (с последующей проверкой)

## 3. Что НЕЛЬЗЯ делать с ИИ

- [ ] Передавать персональные данные клиентов (ФИО, телефоны, email, платежи)
- [ ] Загружать конфиденциальные документы (договоры, финансовые отчёты)
- [ ] Публиковать ответ ИИ без проверки человеком
- [ ] Использовать ИИ для юридических/финансовых решений без верификации

## 4. Правила безопасности

- Данные клиентов — только через внутренние системы, не через публичные ИИ
- Коммерческая тайна — не загружать в облачные ИИ
- Каждый ответ ИИ — проверяется перед отправкой клиенту

| Задача | Инструмент | Примечание |
|---|---|---|
| Тексты на русском | Гигачат / YandexGPT | Данные в РФ |
| Универсальный | RouterAI (через АЛТ) | Мировые модели, рубли |

| Мониторинг | ВежПом | Подписка 150 ₽/мес |

## 6. Ответственность

Нарушение политики (передача ПДн через публичный ИИ) → дисциплинарное взыскание.
