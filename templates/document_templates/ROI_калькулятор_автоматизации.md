# ROI-калькулятор автоматизации (формулы + пример)

## Формула

```
Экономия = (Часов_в_нед × Ставка_₽/час) × 4.33 (нед/мес)
ROI за месяц = (Экономия − Стоимость_инструмента) / Стоимость_инструмента × 100%
Срок окупаемости = Стоимость_внедрения / (Экономия_в_мес − Стоимость_инструмента)
```

## Пример: ИИ-ассистент первой линии

**Исходные:**
- Типовые вопросы: 15 в день × 7 мин = 1.75 ч/день → **~38 часов/мес**
- Ставка сотрудника: 500 ₽/час
- Инструмент: НейроСотрудник, 500 ₽/мес
- Внедрение (разово): настройка + база знаний = 5000 ₽

**Расчёт:**
```
Экономия = 38 ч × 500 ₽ = 19 000 ₽/мес
ROI = (19 000 − 500) / 500 × 100% = 3700% (!)
Окупаемость внедрения = 5000 / (19000 − 500) = 0.27 месяца ≈ 8 дней
```
