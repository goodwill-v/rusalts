Предложения и отзывы по наборам открытых данных направляйте на адрес webmaster@rsoc.ru Условия использования открытых данных: Пользователь без заключения договора с Роскомнадзором может использовать (в том числе повторно) открытые данные свободно, бесплатно, бессрочно, безвозмездно и без ограничения территории использования, в том числе имеет право копировать, публиковать, распространять открытые данные, видоизменять открытые данные и объединять их с другой информацией, использовать открытые данные в некоммерческих и коммерческих целях, использовать для создания программ для ЭВМ и приложений. При использовании открытых данных пользователь обязан: использовать открытые данные только в законных целях; не искажать открытые данные при их использовании; сохранять ссылку на источник информации при использовании открытых данных. Пользователь использует открытые данные на свой риск, при этом Роскомнадзор ответственности не несет. По результатам анализа информационных систем с целью выявления возможности и готовности выгрузки новых данных в формате открытых данных, проведённых в апреле 2026 года не выявлено новых готовых для выгрузки в формате открытых данных сведений.
