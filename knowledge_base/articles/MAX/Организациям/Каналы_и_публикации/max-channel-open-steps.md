# Как открыть канал в МАКС

Составлено 19.11.2026. Канал в МАКС создаётся по одному из трёх путей — выбор зависит
от того, кто владелец и есть ли аудитория.

## 1. Типы каналов

| Параметр | Приватный | Публичный (блогер, А+) | Бизнес / организация | Самозанятый |
|---|---|---|---|---|
| Условия | нет | 10 000 подписчиков (суммарно VK/OK/Дзен/Telegram) + реестр РКН + отметка А+ | ИНН; юрлицам — ЭЦП | статус через Госуслуги |
| Где создаётся | приложение («+» → «Создать канал») | бот @channel_bot | business.max.ru → бот @channel_bot_biz | business.max.ru → сервис «Канал» |
| Виден в поиске | нет | да | да | да |
| Никнейм | вручную | из реестра РКН (изменить нельзя) | формируется автоматически | формируется автоматически |

Практический смысл: **бизнес-канал — единственный путь к публичному верифицированному
каналу без порога в 10 000 подписчиков**. Отметка А+ — про «авторство контента»;
организациям она не нужна.

## 2. Шаги бизнес-пути (организация, ИП, самозанятый)

1. Зайти на **business.max.ru/self** (или через МСП.РФ): вход по номеру телефона → указать **ИНН**.
2. Юрлицо: верификация через **ЭЦП** (подпись актуальна, ИНН сертификата совпадает с ИНН организации). ИП/самозанятый: подтверждение статуса через Госуслуги (для самозанятых сервис «Канал» — с 15.06.2026).
3. После одобрения платформой — бот **@channel_bot_biz** → сервис «Канал» → создать канал.
4. Оформление: аватар (квадрат, от 200×200 px), описание тематики, **сразу первый пост** (пустой канал не оставлять), ссылка-приглашение.
5. Рост: активные каналы МАКС продвигает в рекомендациях ленты; таргетированная реклама через VK Рекламу доступна каналам **от 1 000 подписчиков**.

Типичные проблемы: заявка отклонена — проверить совпадение телефона и данных реестра; ЭЦП не принята — проверить актуальность и ИНН; никнейм не нравится — изменить нельзя (для реестровых каналов имя берётся из реестра РКН).

## 3. Юридическая обязанность (для каналов с ростом)

Каналы **от 10 000 подписчиков регистрируются в реестре Роскомнадзора** (заявка через
форму РКН/Госуслуги). Без регистрации: запрет размещения рекламы и запрет репостов
контента канала (репосты запрещены даже обычным пользователям). Проверено практикой
МАКС: регистрация каналов открыта с 19.03.2026; обязанность — из закона «О информации»
(поправки, действующие с 01.11.2024).

## 4. Путь АЛТ (внутренний план)

Аккаунт business.max.ru у владельца проекта уже есть (см. док исследования
`/opt/alt_docs/ALT_ZAI_devops/MAK_ISSLEDOVANIE_MAX.md`). Последовательность:

1. **Шеф**: вход business.max.ru → ИНН (+ЭЦП, если юрлицо) → @channel_bot_biz → создание канала. Решить **название до создания** (ник генерируется автоматически — проверить, что позволяет ввести читаемое имя).
2. **МАК**: шпаргалка-инструкция по шагам (по факту входа — интерфейс может отличаться от гайдов), пост-старт, контент-план на 2 недели.
3. **Сайт**: добавить канал МАКС в каталог `/channels/` (страница уже живая, поля редактируются в админке).
4. **Бот-публикатор** (отдельная задача после стабилизации): автопубликация контента АЛТ в канал через Bot API — бот добавляется админом в канал и постит `POST /messages`; в репо есть рабочий пример отправки (`app/max_notify.py`).
5. **Кросс-промо**: карточка канала в ботах (механика сезонных /start уже проверялась).

## 5. После открытия — функции канала

Посты, комментарии (вкл/выкл), опросы (с 06.10.2026, включая анонимные и с обложкой), истории, лайвы, статистика канала, отложенный постинг, донаты через VK Donat (публичные каналы, до 10 000 ₽ разово), мини-апп «Channel Tools» (донаты, розыгрыши, лайвы, ресурсы для авторов). Монетизация рекламы — VK Реклама и VK AdBlogger (маркетплейс интеграций, с 02.11.2026).
