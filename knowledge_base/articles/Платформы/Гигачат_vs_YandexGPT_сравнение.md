# GigaChat vs YandexGPT — сравнение российских ИИ-моделей

Две ведущие российские LLM — GigaChat (Сбер) и YandexGPT (Яндекс). Обе доступны через RouterAI и подходят для бизнес-задач. Рассмотрим, когда что использовать.

## Сравнение по задачам

| Задача | GigaChat | YandexGPT |
|---|---|---|
| Анализ текста, извлечение данных | **++** хорошо структурирует | + уверенно, но проще |
| Генерация текстов (статьи, письма) | + длинные ответы | **++** более живые, «человечные» |
| Диалог, поддержка | + адекватен, но формален | **++** естественнее в диалоге |
| Код, технические вопросы | **++** лучше JS/Python/SQL | + базовые задачи |
| Следование инструкциям | **++** чётко выполняет промпт | + иногда упрощает |

## Главные различия

- **GigaChat** — строже следует инструкциям, лучше подходит для структурированных задач: анализ текста, извлечение данных, код, следование сценариям. Если нужна **надёжность выполнения правил** — GigaChat.
- **YandexGPT** — естественнее в диалоге, пишет более человечные ответы. Если нужен **живой разговор с клиентом** — YandexGPT.

## Что выбрать для продуктов АЛТ

АЛТ использует комбинацию моделей для разных задач:
- **GigaChat** — для анализа заявок, квалификации, структурирования данных (там, где важна точность)
- **YandexGPT** — для диалогов с клиентами, генерации черновиков ответов (там, где важна естественность)

В продуктах АЛТ модель выбирается автоматически под задачу. Пользователю не нужно думать, какой API подключить.

## Что это значит для бизнеса
Российские LLM уже на том уровне, чтобы решать реальные бизнес-задачи. GigaChat и YandexGPT не уступают зарубежным аналогам в русскоязычных сценариях, а по соответствию 152-ФЗ — превосходят. Через RouterAI можно использовать обе модели без привязки к одному вендору.
